# 宿主目录挂载（把宿主机目录映射进 jail）

> 版本：0.12.0 起

实例运行在 chroot 的 jail 里，默认只看到自己的 rootfs、home、workspace 和平台运行库。
有时你需要让它读宿主机上的数据（数据集、共享盘、模型权重……），这就是「宿主目录挂载」。

## 1. 在哪里配

**后台** → 「实例」标签页 → **宿主目录挂载** 卡片：

| 栏位 | 说明 |
|---|---|
| 实例 | 挂给哪个实例 |
| 宿主路径 | 宿主机上的**绝对路径**，必须是**已存在的目录** |
| jail 内路径 | 留空 = 与宿主路径相同；也可以写成 `/data/share` |
| 权限 | **只读（推荐）** / 读写 |

下面是表格，列出每条挂载的实例、宿主路径、jail 路径、权限，以及
**宿主路径是否还存在**（`⚠ 宿主路径不存在`）；右侧「移除」删除该条。

**命令行**同样可以：

```sh
dsh-muctl mount list --instance alice
dsh-muctl mount add /srv/datasets /data/datasets --instance alice        # 只读
dsh-muctl mount add /srv/scratch  /data/scratch  --rw --instance alice   # 读写
dsh-muctl mount add /srv/shared   /data/shared   --all                   # 给所有实例
dsh-muctl mount rm  /srv/datasets --instance alice
```

## 2. 生效时机

挂载写进实例的 conf（`EXTRA_MOUNTS="host:jail:mode,..."`），**launcher 在启动时装配**
→ 改完要：

```sh
dsh-muctl instance restart alice
```

后台里改完会有「重启生效」的提示；抽屉里对用户自己的实例也有「有改动要重启」。

## 3. 安全校验（这些都会被拒绝）

| 尝试 | 结果 |
|---|---|
| `/var/lib/dsh-mu`、`/proc`、`/sys`、`/dev`、`/etc`、`/root`、`/usr`、`/boot` | refused：平台内部路径 |
| 其他实例的 jail rootfs（`/var/lib/dsh-mu/instances/bob/rootfs/...`） | refused：不能跨租户 |
| jail 内路径 `/`、`/proc`、`/sys`、`/dev`、`/boot` | refused：会破坏 jail 结构 |
| jail 内路径 `/home/dsh/.dsh*`、`/usr/local/lib*` | refused：会遮蔽平台文件 |
| 宿主路径不存在 / 不是目录 | refused |

默认 **只读**：只有显式 `--rw` / 选「读写」才可写。

## 4. 实测（0.12.0，真机）

```
宿主: /srv/dsh-share  (只读挂到 /data/share)
      /srv/dsh-rw     (读写挂到 /data/rw)

jail 内:
  cat /data/share/readme.txt   → hello-from-host 1792516716     ✓ 可见
  touch /data/share/denied     → Read-only file system          ✓ 只读生效
  touch /data/rw/written       → 成功                            ✓ 可写

宿主侧:
  /srv/dsh-rw/written 出现了                                     ✓ 双向
```

拒绝示例（真实输出）：

```
dsh-muctl: /var/lib/dsh-mu -> /x: refusing to expose platform-internal path: /var/lib/dsh-mu
dsh-muctl: /proc -> /p: refusing to expose platform-internal path: /proc
dsh-muctl: /srv/dsh-share -> /: jail path cannot be /, /proc, /sys, /dev or /boot
dsh-muctl: /nonexistent -> /n: host path does not exist: /nonexistent
```

## 5. 自检

`dsh-muctl doctor` 会为每条挂载输出一行：

```
PASS  mount alice:/data/share    /srv/dsh-share (ro)
WARN  mount alice:/data/share    host path is missing: /srv/dsh-share
      → 重建目录，或 dsh-muctl mount rm …（宿主路径消失后 jail 里会变成空目录，容易被误认为"数据丢了"）
```

## 6. 排障

| 现象 | 原因 / 处理 |
|---|---|
| jail 里路径存在但是空的 | 宿主路径被删了 → `mount list` 会标 `MISSING`，doctor 会 WARN |
| `Read-only file system` | 这条是只读挂载（预期） |
| 改了没效果 | 没重启实例：`instance restart <name>` |
| 权限不对（属主/属组） | jail 内以 uid 0 运行，映射的是宿主上的原 uid；必要时在宿主上 `chown` |
