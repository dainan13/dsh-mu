# 13 · 插件（每个实例自己装，经理人清单与密码把关）

## 一条规则

> **越过管理员清单的操作，都要管理员密码。**

| 操作 | 密码 |
|---|---|
| 从**清单内**安装 | 免密 |
| 装**清单外**的包 | 要管理员密码 |
| 卸载**清单内**（管理员给的） | 要管理员密码 |
| 卸载**清单外**（自己装的） | 免密 |
| 管理员在后台维护清单 | 免密（本来就是管理员会话） |

清单本身没有开关，只有"包名 / 版本 / 说明"三列——所以后台只有一张表加一个输入行。

## 装在哪、怎么生效

- 安装动作 = 在**该实例的 jail 内**执行 `dsh plugin --profile <p> add <pkg>@<ver>`
- 落点 = `~/.dsh/profiles/<p>/node_modules`（实例自己的 home，**可写**；不碰全局只读包、不碰别人的实例）
- 镜像：实例的 `.npmrc` 已指向 `registry.npmmirror.com`，国内安装不慢
- 生效：**重启实例**（抽屉里有「重启」，弹层里也提示了）

## 界面

**抽屉 → 我的插件**
```
我的插件                                  [＋ 安装]
  @scope/dsh-plugin-x  1.2.3 · 由 alice   [清单内]  卸载
  left-pad             1.1.3              [自装]    卸载
```
- 安装弹层：默认"从清单选择"；选「其他」时出现 包名/版本 + **管理员密码**
- 需要密码但没给时，后端返回 `403 {needs_admin_password:true, detail}`，弹层**原地**展开密码框（只多一次点击）

**后台 → 插件**：一张清单表（包名/版本/说明 + 移出清单）+ 一行添加表单，下面是「各实例已装」
（实例 / 插件 / 版本 / 来源 / 操作人）——用户自己装的也在里面，来源列写明 `清单内`/`自装`。无任何开关。

**「有改动要重启」提示**：装/卸插件、增改套餐之后，「我的实例」里会出现一条黄色提示
「有改动要重启才生效」，点「立即重启」直接走重启确认 → 不用自己去找重启按钮。

## 接口

```
GET  /api/plugins                     清单 + 各实例已装（后台 token）
POST /api/plugins                     { action: add|remove, pkg, version, note }

GET  /api/me/plugins                  我的清单 + 我的已装（登录态）
POST /api/me/plugins                  { action: install|uninstall, pkg, version?, admin_password? }
```

后端会先校验包名（`^(@scope/)?name$`）与版本格式，再判策略，再执行，最后记账。

## 记账与重放

- `state.json` 里两处：`plugins_catalog`（清单）与 `instances.<name>.plugins`（装机记录：谁、何时、包、版本、来源）
- 记录来源是 `curated`（清单内）还是 `self`（自装），界面上的徽标就来自它
- 实例的 rootfs 若被重建（重建模板/重装），用 `dsh-muctl instance plugin replay <name>` 按记录重放

## 审计

`plugin.install` / `plugin.uninstall` / `plugin.install.approved`（带 `approved_by`）/
`plugin.catalog.add` / `plugin.catalog.remove`，都在后台「审计」页可见。

## 安全边界（必须知道）

- 插件在**用户自己的 jail** 里运行，看不到别人的实例
- 但它**能读到这个实例的模型 key**（`DSHMU_PLAN_*`）——所以"清单外安装"要管理员密码，等于管理员背书
- 不要给普通用户开 DSH 自带的 `plugin-manager` 界面（它会绕过清单、不留归属记录）；本项目特意没开

## 命令行

```sh
dsh-muctl plugin list|add|remove <pkg> [--version V] [--note "..."]   # 维护清单
dsh-muctl instance plugin list <name>                                 # 看某实例已装
dsh-muctl instance plugin add|remove <name> <pkg>[@ver]               # 管理员代装/代卸
dsh-muctl instance plugin replay <name>                               # 重建后重放
```
