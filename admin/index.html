宿主目录挂载 把宿主机目录映射进 jail

只能挂载宿主机上**真实存在的目录**。会被拒绝的：平台内部路径（/proc /sys /dev /etc /root /usr /boot /var/lib/dsh-mu）、其他实例的 jail 目录、jail 内的 / 与 /.dsh*、不存在的路径。默认只读，需读写请显式选择。改动需重启实例生效。
